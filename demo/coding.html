Valid Brackets

Easy

You are given a string s made only of the characters ( ) { } [ ]. Return true if every opening bracket is closed by the same type of bracket, in the correct order, and every closing bracket has a matching opening bracket. Otherwise return false.

Example 1

Input: s = "()[]{}"
Output: true

Example 2

Input: s = "([)]"
Output: false

Example 3

Input: s = "(("
Output: false

Constraints

  • 0 ≤ s.length ≤ 10⁴
  • s contains only bracket characters
